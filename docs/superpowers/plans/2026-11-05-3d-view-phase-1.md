# 3D view phase 1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ask about a molecule's structure and turn its real PubChem 3D model with your hand.

**Architecture:** Pure logic in a plain C++ header, `model_core.h`, tested on the host like `pwg_raster.h`. Drawing and motion in `model_view.ino`, PubChem fetches in `model_source.ino`. The main sketch gains a third display mode, `SHOW_MODEL`.

**Tech Stack:** ESP32 Arduino, M5GFX sprites, MPU6886 gyro, `WiFiClientSecure`, ArduinoJson.

**Spec:** `docs/superpowers/specs/2026-11-05-3d-view-design.md`

## Global Constraints

- Molecule up to 200 atoms, 250 bonds; above that, not available.
- Whole lookup 10 s, then the Wikipedia picture.
- Target 15 fps at 100 atoms; 8 fps floor from 100 to 200 atoms. Atoms, bonds and hydrogens are never dropped.
- Motion dead-band about 15 deg/s; hard cap 5 minutes without a button press.
- The AI supplies only `"model": "molecule:<English name>"`; the label comes from PubChem's Title.
- Fetch first, allocate the sprite after; free it when leaving the view.
- `./verify.sh` must pass. Keep `USERGUIDE.md`, `REQUIREMENTS.md`, `RELEASE_NOTES.md` current.
- Never run `git add -A` here. Never push from this plan.

## Review Focus

- PubChem answers 200 with a truncated or non-SDF body: treated as not available, picture fallback, no crash. Test: `parseSdf` broken inputs (Task 1).
- WiFi drops or PubChem hangs during lookup: picture fallback inside 10 s. Test: hand check with a bad host via `model` command (Task 3).
- Stick lying still in 3D view: sleeps on normal timers. Hand check with serial log (Task 4).
- Timer fires during 3D view: alert takes over, dismissal returns to the model. Hand check (Task 4).
- No memory for the sprite: stays on text with a short note, no crash. Test: forced allocation failure via serial flag (Task 2).

### Task 1: Pure core with host tests

**Files:**
- Create: `sketch/sketch_jan12a/model_core.h`, `sketch/sketch_jan12a/atom_table.h`, `scripts/make_atom_table.py`
- Test: `tests/model/test_model.cpp`, `tests/model/run.sh`, `tests/model/fixtures/caffeine.sdf`, `tests/model/fixtures/water.sdf`

**Interfaces:**
- Produces:
  - `enum ModelKind { MODEL_NONE, MODEL_MOLECULE };`
  - `struct ModelRef { ModelKind kind; char query[64]; };`
  - `bool parseModelRef(const char* text, ModelRef& out);`
  - `struct ModelAtom { float x, y, z; uint8_t element; };`
  - `struct ModelBond { uint8_t a, b, order; };`
  - `struct ModelMolecule { uint16_t atomCount, bondCount; ModelAtom atoms[MODEL_MAX_ATOMS]; ModelBond bonds[MODEL_MAX_BONDS]; };`
  - `bool parseSdf(const char* text, size_t len, ModelMolecule& out);` centres atoms and scales the largest radius to 1.
  - `struct Mat3 { float m[9]; }; void mat3Identity(Mat3&); void mat3Rotate(Mat3&, float rx, float ry, float rz);` applies small rotations in radians and re-orthonormalises.
  - `void rotatePoint(const Mat3&, float x, float y, float z, float out[3]);`
  - `void sortByDepth(const float* z, uint8_t* order, uint16_t n);` insertion sort, far first; order persists between frames.
  - `uint8_t elementFromSymbol(const char* s);` 0 if unknown.
  - `uint16_t elementColor565(uint8_t element); const char* elementSymbol(uint8_t element);`

- [ ] **Step 1: Write failing tests** with these assertions:
  - `parseModelRef`: `"molecule:caffeine"` gives `MODEL_MOLECULE`, `"caffeine"`; `""`, `"molecule:"`, `"sphere:x"`, `":x"`, a 64-character query and a control character all return false with `MODEL_NONE`.
  - `parseSdf`: caffeine has 24 atoms, 25 bonds; water has 3 atoms, 2 bonds, element 8 first; largest radius 1 within 0.001.
  - `parseSdf` false for: empty, HTML, caffeine cut in half, counts line 201 atoms, 251 bonds, a bond naming atom 99, unknown element.
  - `mat3Rotate`: 1000 small rotations leave a unit vector's length within 0.001; pi/2 about z moves (1,0,0) to (0,1,0) within 0.01.
  - `sortByDepth`: far first; already sorted stays.
  - `elementColor565(6)` is the 565 form of `909090`; `elementSymbol(8)` is `"O"`.

- [ ] **Step 2: Run `tests/model/run.sh`.** Expected: fails to compile, `model_core.h` not found.
- [ ] **Step 3: Generate `atom_table.h`** with `scripts/make_atom_table.py` from `https://pubchem.ncbi.nlm.nih.gov/rest/pug/periodictable/JSON`: symbol and RGB565 per atomic number.
- [ ] **Step 4: Implement `model_core.h`.** No Arduino includes. SDF: V2000 only, counts on line 4, atom symbol at columns 32-34, bond columns 1-3, 4-6, 7-9.
- [ ] **Step 5: Run `tests/model/run.sh`.** Expected: `All model tests passed`.
- [ ] **Step 6: Commit** those files, plus spec and plan.

### Task 4: `SHOW_MODEL` mode and groundwork

**Files:**
- Modify: `sketch/sketch_jan12a/sketch_jan12a.ino`, `sketch/sketch_jan12a/screenshot_tour.ino`

**Interfaces:**
- Consumes: Tasks 2 and 3.
- Produces: `void showModelView(); void leaveModelView(); void modelViewTick();`

- [ ] **Step 1: Add the mode.** `DisplayMode` gets `SHOW_MODEL`. Restore paths: `handleLightSleepWake`, `handleDeepSleepWake`, `redrawPreviousResult`, timer alert dismissal, `updateGyroPower`.
- [ ] **Step 2: Add input rules.** In `SHOW_MODEL`, `loop()` skips the orientation block, `detectRollGesture` and `detectShakeGesture`, resets the rotate-toggle statics, and locks rotation. Button B click cycles 3 zoom steps; Button C returns to text; from text with `hasModel`, Button C and rotate-to-toggle enter 3D. Button B hold does nothing, 3 s still resets WiFi.
- [ ] **Step 3: Add motion.** `modelViewTick` runs one non-blocking frame per loop, capped at 25 fps. Gyro integrated, amplified 2x, ignored until `gyroReady()`. Under the dead-band: slow idle rotation.
- [ ] **Step 4: Add sleep.** Above the dead-band refreshes `lastActivityTime`, unless more than 5 minutes since the last button press. Track `lastModelButtonTime`.
- [ ] **Step 5: Add persistence.** Save and restore `modelRefText` in Preferences; deep-sleep wake fetches again. On failure drop to text.
- [ ] **Step 6: Add footer and legend.** Footer `<label> · PubChem`; legend of element letters in colour. Add a 3D hint icon in the rotate icon's place. Add the view to `tour`.
- [ ] **Step 7: Handle no memory.** `modelViewBegin()` false: stay on text, show a short note.
