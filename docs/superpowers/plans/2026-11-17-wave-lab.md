# Wave Lab Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A new physics scene `wave-lab` ("Wellenlabor"): tilt to slide pitch and loudness, B steps through seven waves and patterns, a small view menu switches the sound on and off.

**Architecture:** Pure math in `wave_lab_core.h` (host-tested). The scene draws through the existing physics pipeline (`physics_draw_wavelab.h`) and only *describes* the sound it wants (`PhysicsState::labSound`); `feature_physics.ino` reads the tilt and streams that sound as queued whole-cycle tone pieces. A generic view menu (`view_menu_core.h` + `view_menu.ino`) shows a feature's own rows plus "Text" and "Schliessen", through three new `EduFeature` hooks shaped as ai-stick-0a's button module will adopt them.

**Tech Stack:** Arduino C++ on ESP32 (M5StickC Plus2: M5Unified 0.2.12; StickS3: 0.2.29), host tests with c++17 + ASan/UBSan.

**Spec:** `docs/superpowers/specs/2026-11-16-wave-lab-design.md`

## Global Constraints

- Pitch: 440 Hz with the stick level, 40 degrees of tilt per octave, clamped to 220–880 Hz; right edge down = higher.
- Loudness: the tilt at opening (and at "Ton an") is the middle (0.6); 30 degrees to full (1.0) or quiet (0.2); top edge away = louder; never 0.
- Sound is off at every opening, after "Text" and back, and after a gap of more than 1 s between frames (screen dark, light sleep, alert).
- Scale 60 px per metre, sound speed 343 m/s (`PHYSICS_SOUND_SPEED`), wave moves at 94 px/s (`PHYSICS_SOUND_SCREEN_SPEED`), "Zeitlupe"/"slowed" on screen.
- Patterns in order: Sinus/Sine, Dreieck/Triangle, Rechteck/Square, Sägezahn/Sawtooth, Oktave/Octave (2f), Quinte/Fifth (3f/2), Schwebung/Beat (f + 4 Hz).
- Note names as `musicNoteName()`: German C Cis D Dis E F Fis G Gis A Ais H, English C C# D D# E F F# G G# A A# B, plus octave number, prefixed with a drawn "≈".
- Keep-awake only while sound is on and tilt moved in the last 30 s; 5 minutes after the last press (B, a menu press, opening) the sound switches itself off.
- Speaker: lower tone channel 1, upper tone channel 2, channel 0 untouched; `end()` stops 1 and 2 and restores their `getChannelVolume()` values. Device volume never changed.
- Menu hook (ai-stick-0a, verbatim): `int (*menuRowCount)(); const char* (*menuRowLabel)(int i, bool german); bool (*menuRowChoose)(int i);` appended at the end of `EduFeature`; labels ≤ 17 characters and ≤ 174 px in the 12 pt menu font; `true` = keep the menu open and redraw.
- The lab's `hints()`: `kindB = HINT_NEXT`, `kindC = HINT_NONE`.
- Gate: `tests/run_all.sh` and `./verify.sh` (both boards) pass. No merge to main; ai-stick-ef owns the queue.

## Review Focus

1. Sound after leaving: Button A, menu "Text", a timer alert, the screen going dark — no tone may continue. Pinned by Task 4's exit checklist on the device and Task 2's render check that `labSound.count == 0` whenever `labSoundOn` is false.
2. Stick held flat or upside down: the tilt maths must not produce NaN or jump to the far end. Pinned in Task 1 (`waveLabPitchTiltDeg`/`waveLabLoudTiltDeg` for flat, upright, upside-down and zero vectors).
3. Holding B to open the menu must not run on into the 3 s WiFi reset, and the menu's clicks must not come back as a single/double/triple press. Pinned in Task 3 (sets `buttonBHeldForMenu`, calls `forgetButtonBClicks()`), checked by hand in Task 4.
4. Menu open while the lab animates: A must choose a row, never start a recording. Pinned in Task 3 (`discardButtonA(0)` around a choose, as `homeMenuTick` does).
5. Text overlap at the extremes (880 Hz "39 cm", "+ Oktave 1760 Hz", English and German, sound on/off). Pinned in Task 2's render sweep.

  - `enum WaveLabShape : uint8_t { WAVE_SHAPE_SINE, WAVE_SHAPE_TRIANGLE, WAVE_SHAPE_SQUARE, WAVE_SHAPE_SAW, WAVE_SHAPE_COUNT };`
  - `struct WaveLabPattern { const char* de; const char* en; uint8_t shape; float ratio; float offsetHz; };` and `static const WaveLabPattern WAVE_LAB_PATTERNS[7]` (ratio 0 = one tone; octave ratio 2, fifth 1.5, beat ratio 1 + offset 4; the two-tone ones use the sine shape); `WAVE_LAB_PATTERN_COUNT 7`
  - `float waveLabHz(float pitchTiltDeg)`
  - `float waveLabLoudness(float loudTiltDeg, float zeroDeg)`
  - `float waveLabPitchTiltDeg(float gx, float gy, float gz)` — asin of the screen x component of gravity over its length, degrees; 0 for a zero vector
  - `float waveLabLoudTiltDeg(float gx, float gy, float gz)` — `atan2(gz, gy)` in degrees; 0 for a zero vector
  - `float waveLabShapeValue(uint8_t shape, float turns)` — band-limited, −1..1, harmonics 1..`WAVE_LAB_HARMONICS`: sine = h1; square = odd h, 1/n; saw = all h, 1/n; triangle = odd h, 1/n², alternating sign; each normalised so its peak over a cycle is 1
  - `const uint8_t* waveLabTable(uint8_t shape)` — `WAVE_LAB_TABLE_LEN` unsigned 8-bit samples of one cycle, `128 + round(115 * value)`, filled once into static storage on first call and never changed (the speaker keeps the pointer)
  - `float waveLabSecondHz(const WaveLabPattern& p, float hz)` — 0 when `p.ratio == 0`, else `hz * p.ratio + p.offsetHz`
  - `void waveLabNoteName(float hz, bool german, char* out, size_t size)` — nearest MIDI note `lround(69 + 12 log2(hz / 440))`, name + octave `(midi / 12) - 1`, no "≈"
  - `bool waveLabKeepAwake(uint32_t now, uint32_t lastMove, uint32_t lastPress)` — `now - lastMove < WAVE_LAB_MOVE_AWAKE_MS && !waveLabPressTimedOut(now, lastPress)`
  - `bool waveLabPressTimedOut(uint32_t now, uint32_t lastPress)` — `now - lastPress >= WAVE_LAB_PRESS_CAP_MS` (unsigned, survives the millis() wrap)
